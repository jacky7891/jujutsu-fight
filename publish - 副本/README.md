# 咒术回战 · 五条悟 vs 两面宿傩

浏览器里的 2D 对战（HTML5 Canvas，**单文件、零依赖、离线可玩**）。

线上地址：把本目录推到 GitHub 仓库并开启 Pages（见下方「部署」），
访问形如 `https://<你的用户名>.github.io/<仓库名>/`

---

## 部署到 GitHub Pages

### 方案 A：完全不用下载任何东西（网页上传，3 步）

1. 打开 https://github.com/new 新建仓库（**Public**，名字随意，例如 `jujutsu-fight`，其它选项都别勾）
2. 仓库首页点 **Add file → Upload files**，把下面几个文件拖进去 → Commit
   - `index.html`（必须，游戏本体）
   - `.nojekyll`（可选，避免 GitHub 的 Jekyll 处理）
   - `README.md`（可选，就是本页说明）
3. **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、文件夹选 `/ (root)` → Save

30 秒～2 分钟后页面顶部会给出公网地址。**第一次访问 404 是正常的**，多等一会儿再刷新。

> 更新游戏：网页上重新上传 `index.html` 覆盖即可（同名文件会被替换）。

### 方案 B：用命令行（以后更新更省事）

需要下载：[Git for Windows](https://git-scm.com/download/win)（安装时一路 Next 即可），
或图形界面的 [GitHub Desktop](https://desktop.github.com/)（不用记命令）。

```bash
git init
git add index.html .nojekyll README.md
git commit -m "add jujutsu-fight"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

推完同样去 **Settings → Pages** 开启（选 `main` / `/ (root)`）。

> 本目录里的 `CNAME`、`deploy.ps1`、`serve_pub.js`、`sync.ps1` 是给 surge 部署用的，
> 上传到 GitHub 时可以不带（带也不影响运行）。

## 联机对战（房间码）

标题界面点「联 机 对 战」（或按 `3`）：

1. 一方点 **创 建 房 间**，得到 6 位房间码 → 点 **复制房间码** 发给朋友
2. 另一方在「房间码」输入框填入 → 点 **加 入**
3. 双方各自选角色（房主＝玩家 1，加入者＝玩家 2），都确认后自动开局

创建者用 **P1 键位**（WASD · J 拳 · 空格闪避），加入者用 **P2 键位**（方向键 · 0 拳 · / 闪避）。

> 联机走浏览器 P2P 直连（PeerJS 公共信令），需要双方都能上网。
> 房主运行整场战斗并把画面状态实时广播给对手；对手断线会自动提示并退回标题。

## 玩法

角色选择页：**P1** `A/D` 选人、`J` 确认；**P2** `←/→` 选人、`0` 确认；人机模式由电脑自选；触屏可直接点卡片。

### 共用操作

| 操作 | P1 | P2 |
|---|---|---|
| 移动 | `A` / `D` | `←` / `→` |
| 跳（空中再按＝二段跳） | `W` | `↑` |
| 防御 | `S` | `↓` |
| 拳（连按＝三连段） | `J` | `小键盘0` / `0` |
| **闪避**（长距突进 + 无敌帧，可取消出拳后摇） | **空格** | `/` |

- 体质：**血量 450**。
- **连击保护**：被连续压制满 5 秒会自动挣脱（解除硬直 + 1.5 秒无敌 + 击退对手），不会被一套连到死。

### 黑闪

每一丝普攻都有 **5%** 概率骤然黑闪（无保底，可连出也可能整局不出）。
黑闪的威力是该拳伤害的 **2.5 次方**，并按打出的伤害回复自身体力（30%，上限 12）。
